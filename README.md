#  Linear Regression

This repository contains beginner Machine Learning projects built using **Simple Linear Regression** with **scikit-learn**.

## Projects

### 1. House Price Prediction
Predict house prices using house area.

**Concepts Covered**
- Data visualization
- Model training
- Predictions
- Exporting predictions to CSV
- Model evaluation

---

### 2. Canada Per Capita Income Prediction
Predict Canada's future per capita income using historical data.

**Concepts Covered**
- Trend analysis
- Future predictions
- Regression line visualization
- Model evaluation
